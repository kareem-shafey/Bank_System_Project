Bank Management System - Evolution Series
This repository showcases the progressive development of a Bank Management System as part of the Abu-Hadhoud Programming Roadmap. The project is organized into three phases, reflecting the growth in programming skills, logic complexity, and software architecture from Course 7 to Course 8.

📂 Repository Structure
The project is divided into three main directories:

1. 01-Bank-System-Initial (Course 7 - Project 1)
Focus: Core fundamentals of C++ and File Handling.

Key Features:

Basic CRUD operations (Create, Read, Update, Delete) for clients.

Data persistence using Flat Files (.txt).

Record searching and listing.

Simple Console UI.

2. 02-Bank-System-Extensions-V1 (Course 7 - Extensions)
Focus: Logic expansion and functional improvements.

Key Features:

Transactions Menu: Deposit, Withdraw, and Total Balances.

Enhanced data validation to prevent incorrect inputs.

Improved UI flow and navigation between menus.

3. 03-Bank-System-Extensions-V2 (Course 8 - Final Project)
Focus: Advanced logic, security, and professional structure.

Key Features:

Login System: Secure access with username and password.

Permissions System: Restricting specific users from accessing certain menus (e.g., Admin vs. User).

Currency Exchange: Integration of currency conversion logic (if applicable in your version).

Optimized Codebase: More modular functions and advanced date/time handling.

🛠️ Technical Stack
Language: C++

Paradigm: Procedural Programming / Structured Programming.

Storage: Text-based Database (File Streams).

Tools: Visual Studio / Any C++ Compiler.
